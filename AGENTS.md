# Repository instructions

- Before starting any work in this repository, run `git pull` to bring the current branch up to date. If the pull cannot be completed because of conflicts, missing upstream configuration, or authentication/network issues, resolve or report that before proceeding with implementation.
- Build the website as static files suitable for hosting on Amazon S3. Use client-side HTML, CSS, JavaScript, and static assets only; do not add server-side code or require a running application server.
